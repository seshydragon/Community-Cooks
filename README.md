# Community Cooks

Community Cooks is a front-end cooking community concept built for FBLA Website Design.

## Stack

- HTML
- CSS
- JavaScript
- Browser localStorage for demo persistence
- Unsplash-hosted food photography

No framework, build system, or TypeScript is required.

## Run locally

Open index.html in a browser.

For a local Python server:

    python -m http.server 8000

Then open http://localhost:8000.

## Product demo

- Recipe discovery and search
- Recipe category filters
- Save recipes with localStorage
- Add a recipe through a working form
- Weekly challenge interaction
- Community leaderboard
- Personal cooking points
- Cook mode interaction
- Responsive desktop and mobile layouts

## Design direction

Community Cooks uses an editorial food-magazine approach rather than a generic app-dashboard aesthetic. The visual system uses warm paper tones, olive green, restrained rust accents, serif display typography, photography, visible borders, and asymmetric spacing.

The site intentionally avoids generic AI-dashboard patterns, excessive rounded cards, gradients, neon colors, purple/black palettes, fake testimonials, emoji-based UI, terminal imagery, skeleton loading screens, and decorative filler.

## FBLA

The site is designed around the Website Design event's emphasis on front-end layout, navigation, aesthetics, and user experience.
